
# MyVerse

MyVerse is a creative sharing platform where artists and creators can showcase their work, discover other creators, and connect through creativity.

## Current Progress

- Initial static homepage UI completed.
- Frontend structure and layout in progress.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- HeroUI
- Lucide React

## Planned Features

- User authentication and profiles
- Creative posts (artwork, stories, and videos)
- Like, comment, and save functionality
- Follow artists and discover creators
- Personalized feed and trending topics

## Project Status

Currently in development.
